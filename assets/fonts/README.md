SIL Open Font License 1.1, which allows self-hosting and redistribution.

- instrument-serif-*.woff2: Instrument Serif (Instrument), display headings.
- libre-caslon-condensed-latin.woff2: Libre Caslon Condensed (Pablo Impallari), used only
  for the hyphen glyphs in headings (Instrument Serif's hyphen has wide side bearings).
